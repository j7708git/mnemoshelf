## v0.9.3 重點

聚焦記憶信噪比提升、專案級自動注入控制、Antigravity Hook 去重清洗與 MCP 短記憶更正：

- **Antigravity Hook 去重與原文清洗**：`PreInvocation` 預設改為 `per-turn`（依 `initialNumSteps` 與 `promptHash`／`lastInjectedBlockHash` 去重），移除含記憶關鍵字時同回合每步重複注入；`Stop` 與查詢前處理剝除宿主 `<SYSTEM_MESSAGE>`、`<ADDITIONAL_METADATA>`、`<USER_SETTINGS_CHANGE>` 與帶 `tool_calls` 的過場步驟，並拆殼保留 `<USER_REQUEST>` 本文。
- **精煉記憶優先分層召回**：`POST /memories/search` 新增精煉記憶優先排序（語意 `+0.08` 軟加權、關鍵字 `0.7×` 等效名次；保留原始 cosine／`1/rank` 分數，`pinned` 仍不影響排名），`dsh-plugin` 與 `opencode-plugin` 同步改為先裝精煉記憶、剩餘預算由 `raw-turn` 補位；`hook-core` 新增純指令與 `< 6` 字元低資訊短句自動略過護欄。
- **專案級自動注入開關（保留 MCP 主動搜尋）**：新增 `GET / PATCH /memory-auto-inject` 與 Web UI「召回規則 → 自動注入設定」面板，支援全域預設與專案覆寫三模式（`all`／`refined-only`／`off`）。設為 `off` 時 `channel: "auto"` 會在 `embedQuery` 前短路（零推論、零注入 token），但不影響 MCP `search_memories`／`recall` 或手動預覽。
- **MCP 短記憶更正**：新增 `update_memory` 工具，沿用 `supersedes` 建立新版並保留去重維度與組織快照。
- **評測工具擴充**：Stage 3 評測加入 `no-memory`／`antigravity-hook` 對照與 Reader `prompt_tokens`／`completion_tokens` 彙總，新增 `TIERED_EVAL` 混合語料分層評測。

## 升級與回滾

1. 升級前先完全結束服務並備份資料目錄；PostgreSQL 使用者先建立資料庫備份。
2. 首次啟動會套用資料庫遷移 `0011_memory_auto_inject`，建立 `memory_auto_inject_settings` 並初始化為 `defaultMode: "all"`；既有記憶內容、ID、向量、召回規則與組織快照原樣保留。
3. 回滾時請同時換回舊版 App 與升級前的資料庫備份，避免舊服務操作已升級的資料庫。
4. 完整啟用新版 Antigravity／Codex Hook 去重清洗與自動注入開關，請同步重新建置並更新 Hook 腳本與外掛；更新 App 不會自動改寫宿主設定檔。

詳細契約見 [記憶整理與召回規則](https://github.com/j7708git/mnemoshelf/blob/v0.9.3/docs/memory-organization.md) 與 [Hook 接入指引](https://github.com/j7708git/mnemoshelf/blob/v0.9.3/docs/hook-integration.md)，備份與還原步驟見 [更新說明](https://github.com/j7708git/mnemoshelf/blob/v0.9.3/docs/updates.md)。

## 已知界線

- 本版跨版本 App 內更新與安裝後各宿主完整對話流程尚未實機驗證；macOS 持續只檢查並開啟下載頁（ad-hoc 簽章、未公證），Windows 安裝包未簽章。
- 自動注入開關與召回規則皆為本機單一 owner 的使用偏好，不構成多使用者權限隔離。
- Stage 3 評測在未配置真實回答模型端點時僅輸出離線檢索與字元指標，Reader 欄位標註為 `NOT_RUN`。
